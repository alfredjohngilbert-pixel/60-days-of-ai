# 🛡️ Defend Your Experience

## Day 50 — #60DayClaudeChallenge

An AI-powered interview preparation application that challenges every claim you make, helping you prepare for interviews with confidence.

## Features

- Upload project descriptions
- Paste project details
- AI claim extraction
- Multiple interviewer personas
- Cross-examination simulation
- Confidence score
- Defense report
- Export results
- Print to PDF
- Responsive dark interface

## Tech Stack

- HTML
- CSS
- JavaScript
- Claude AI

## What I Learned

Preparing for interviews isn't about memorizing answers.

It's about defending every statement with confidence, evidence, and real examples.
