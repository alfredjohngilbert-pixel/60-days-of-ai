# 🚀 Day 51 – 10-Day Capstone Project

> AB Talks 60-Day Claude AI Challenge

## 📌 Project

**Admissions Lead Tracker**

A browser-based application designed to help school admission staff manage inquiries from the first phone call through the final admission decision.

---

## 🎯 Project Goal

Build a simple, practical application that ensures **no admission lead is ever forgotten** by providing an easy way to manage leads and track follow-ups.

---

## 💡 Biggest Scoping Decision

To complete the project within **10 days**, I focused on solving **one core problem**:

> **"Who do I need to call today?"**

Instead of building every possible feature, I deliberately limited the first version to essential functionality.

### Included in Version 1

- ✅ Add, edit, and delete leads
- ✅ Five-stage admission funnel
- ✅ Follow-up tracking
- ✅ Dashboard with today's follow-ups
- ✅ Browser Local Storage
- ✅ Responsive UI

### Deferred for Future Versions

- Multi-user accounts
- Cloud synchronization
- WhatsApp/SMS integration
- CSV/Excel import & export
- Advanced analytics
- Automated notifications

---

## 🛠 Tech Stack

- CSS3
- JavaScript (Vanilla)
- Browser Local Storage
