# 🦈 AI Shark Tank Simulator

An interactive AI-powered startup pitching simulator where founders present their business, answer investor questions, receive AI feedback, and get an investment decision.

Built for **Day 25** of the **#60DayClaudeChallenge**.

---

## 🚀 Features

- Startup Pitch Form
- AI Investor Questions
- Investment Decision
- Business Evaluation
- Downloadable Report
- Responsive Modern UI
