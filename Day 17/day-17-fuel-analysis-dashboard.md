# Day 17 – Fuel Analysis Dashboard 🚗📊

Part of the #60DayClaudeChallenge

## Project Overview

This dashboard analyzes different fuel options for the Kia Carens Clavis GTX+ Turbo DCT and compares:

- Petrol
- Diesel
- CNG
- EV
- E85 (Ethanol Blend)

The goal is to help users make data-driven decisions by evaluating:

- Cost per kilometer
- Monthly fuel expenses
- CO₂ emissions
- Maintenance costs
- Fuel suitability scores
- Vehicle age impact on ownership costs

## Key Insight

One surprising discovery was that E85 appeared cheaper than Petrol on a cost-per-kilometer basis despite having lower fuel efficiency.

Data visualization helped reveal the relationship between:
- Pump price savings
- Running efficiency penalties
- Break-even pricing
- Long-term ownership economics

This demonstrated that fuel decisions require looking beyond mileage alone.

## Features

✅ Fuel Cost Comparison

✅ Emissions Analysis

✅ E85 Break-even Calculator

✅ Vehicle Age Cost Analysis

✅ Interactive Charts

✅ Fuel Suitability Score

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js

## Learning Outcome

This project reinforced how data visualization can transform raw vehicle data into actionable insights and uncover patterns that are difficult to identify from tables alone.
