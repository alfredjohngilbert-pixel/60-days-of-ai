# Day 44 – AI-Powered LinkedIn Optimizer 🚀

## Overview

An AI-powered web application that analyzes LinkedIn profiles and provides actionable recommendations to improve personal branding, recruiter visibility, and profile performance.

Built as part of the **#60DayClaudeChallenge**.

## Features

- 🔍 LinkedIn Profile Review
- 🔥 Honest "Roast & Rebuild" Analysis
- 📊 Profile Scorecard
- ✍️ AI-Generated Headline Suggestions
- 📝 About Section Optimization
- 💼 Experience Enhancement
- 🎯 Skills & Keyword Recommendations
- 📈 Before vs After Score Comparison
- 📅 Personalized 7-Day LinkedIn Growth Plan
- 🎨 Premium Dark UI Design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Claude AI (Anthropic API)
