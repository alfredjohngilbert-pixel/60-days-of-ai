# Day 39 – PDF Splitter & Merger

## Project Overview
A browser-based PDF utility built with HTML, CSS, and JavaScript.

## Features
- Split PDFs by custom page ranges
- Merge multiple PDF files
- Drag & Drop upload
- Client-side PDF processing
- Responsive UI
- Dark theme

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PDF-LIB

## Learning Outcome
Learned how browser-based PDF processing works using JavaScript while keeping user files private by processing everything locally.
