# Day 20 - Face Puzzle Game 🧩

## Overview
A browser-based Face Puzzle Game created with AI assistance during the #60DayClaudeChallenge.

The game captures a photo using the device camera, converts it into puzzle pieces, and challenges the player to solve the puzzle as quickly as possible.

## Features

- 📸 Camera Photo Capture
- 🧩 3×3, 4×4, and 5×5 Difficulty Levels
- ⏱️ Real-Time Timer
- 🔄 Move Counter
- 🏆 Personal Best Time Leaderboard
- 📱 Responsive Design
- 🎯 Drag-and-Drop Puzzle Mechanics

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Camera API (getUserMedia)
- Local Storage

## Challenge Results

- Fastest Time: 00:02.9
- Difficulty: 4×4
- Moves: 1

## Key Learnings

- Working with Camera APIs
- DOM Manipulation
