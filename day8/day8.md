# 🎓 Day 8 – AI School Intelligence Command Center

## 📌 Project Overview

An AI-powered School Intelligence Dashboard designed for Principals, Directors, and School Administrators.

The application analyzes student performance data from Excel files and generates leadership-level insights.

---

## 🚀 Features

### 📊 Executive Dashboard
- Total Students
- Average Attendance
- Average Academic Score
- School Health Score

### 🤖 AI Principal Copilot
- Executive Summary
- School Performance Insights
- Intervention Recommendations

### 📈 Analytics
- Grade Distribution Chart
- Risk Distribution Chart
- Top 10 Students Leaderboard
- At-Risk Student Detection

### 📂 Data Support
- Excel (.xlsx) Upload
- Automatic Analysis
- Dynamic Dashboard Updates

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- SheetJS (XLSX)

---

## 📁 Dataset

Sample Dataset:

- 120 Students
- Attendance Records
- Academic Scores
- Risk Levels
- School Health Metrics
