# Think Like a Marketing Strategist

Day 32 of the #60DayClaudeChallenge

An interactive marketing strategy simulator that teaches beginners how marketers think—not just how to create marketing content.

## Features

- Audience-first marketing
- Platform selection
- Content pillar strategy
- 30-day roadmap
- Unexpected marketing events
- Growth Report
- Claude prompt generator
- Fully responsive
- Single HTML file
- React + Babel CDN

## Built With

- HTML
- CSS
- JavaScript
- React
- Babel
