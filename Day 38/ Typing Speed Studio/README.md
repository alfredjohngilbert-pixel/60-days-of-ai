# Day 38 – Typing Speed Studio

## Overview
Typing Speed Studio is a modern typing practice application built using HTML, CSS, and JavaScript. It helps users improve typing speed while providing detailed real-time analytics and performance insights.

## Features

- ⌨️ Multiple typing modes
  - Time Mode
  - Word Count
  - Quote Mode
  - Programming Mode
  - Custom Text
  - Adaptive Mode
  - Zen Mode

- 📊 Real-time Analytics Dashboard
  - WPM
  - Raw WPM
  - Accuracy
  - Mistakes
  - Streak
  - Consistency

- 📈 Performance Graphs

- 🔥 Error Heatmap

- 📜 Session History

- 🎨 Dark Professional UI

- ⚡ Keyboard Shortcuts

- 💾 Local Storage Support

## Tech Stack

- HTML5
- CSS3
- JavaScript

## What I Learned

Building this project taught me how to:

- Track typing performance in real time
- Calculate WPM and typing accuracy
- Store session history using Local Storage
- Build interactive dashboards
- Create a smooth user experience with JavaScript
