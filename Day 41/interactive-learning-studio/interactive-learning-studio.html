Module 1: let & const

Objective: Learn block scoped variables.

const pi=3.14;
let count=0;

Analogy: const is a sealed label; let is a whiteboard.

Quiz

Which keyword allows reassignment?




Cheat Sheet

  • const: cannot be reassigned
  • let: block scoped & reassignable
  • Prefer const by default.
