# Day 33 – Media Integrity Analyzer

## 📌 Overview
The Media Integrity Analyzer is an interactive learning tool designed to improve media literacy. It helps users recognize misleading headlines, emotional manipulation, and clickbait by analyzing realistic scenarios and explaining the psychology behind them.

This project was created as part of my #60DayClaudeChallenge.

## ✨ Features

- Analyze misleading headlines
- Detect emotional manipulation techniques
- Learn about clickbait and media bias
- Interactive challenges
- Media Integrity Dashboard
- Responsive design
- Runs completely offline

## 🧠 What I Learned

The biggest lesson from this project was that emotional language often influences our decisions before we verify the facts.

Instead of trusting headlines immediately, it's important to:
- Read the full article
- Verify the source
- Look for evidence instead of emotional wording
- Think critically before sharing information
