# 🏥 Prior Authorization Workflow Simulator

An interactive healthcare education simulator that demonstrates the complete Prior Authorization process.

## Features

- Interactive drag-and-drop workflow
- Multiple patient scenarios
- Provider, Patient & Insurance lanes
- Progress tracker
- Educational popups
- Efficiency scoring
- Approval, denial and appeal simulation
- Responsive design

## Built With

- HTML5
- CSS3
- JavaScript

Coming soon via GitHub Pages.

## Learning Outcomes

- Understand the Prior Authorization workflow
- Learn role-based healthcare coordination
- Explore approval and appeal processes
- Visualize workflow efficiency
