# 🚚 AI Supply Chain Control Tower

An AI-powered Supply Chain Control Tower simulation built with HTML, CSS, and JavaScript as part of **Day 31** of the #60DayClaudeChallenge.

## ✨ Features

- Real-time operational alerts
- Live KPI dashboard
- Event log
- Decision-based outcomes
- Supply chain optimization simulation
- Performance scoring

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📊 KPI Dashboard

- Service Level
- Customer Satisfaction
- Inventory Health
- Transport Efficiency
- Operating Cost
- Revenue Protected
