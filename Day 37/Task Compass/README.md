# Day 37 – Task Compass

## Overview

Task Compass is an interactive workflow simulator that teaches organizational thinking through three challenges:

- Who Owns This?
- Task Routing
- Collaboration

Users learn how responsibilities move across different roles in a school or university environment.

---

## What I Learned

- Ownership creates accountability.
- Delegation improves efficiency.
- Collaboration solves complex problems better than individual effort.
