🎓 Admission Readiness Simulator

A professional School Admission Readiness Simulator built using HTML, Tailwind CSS CDN, and Vanilla JavaScript.

The simulator places the user in the role of a School Admission Coordinator, guiding them through admission workflows, document verification, seat allocation, fee verification, and final readiness analysis.

⸻

✨ Features

* 📋 Student Admission Case Setup
* 📊 Dynamic Admission Readiness Score
* ✅ Application Status Analysis
* 📄 Document Verification Workflow
* 💰 Fee Verification
* 🪑 Seat Allocation
* 👨‍🏫 Principal Approval Tracking
* 👨‍👩‍👦 Parent Consent Management
* 📈 Interactive Timeline
* ⚠ Risk Tracking
* 👥 School Coordination Cards
* 📑 Governance Snapshot
* 🎯 Final Admission Decision Engine

⸻

🛠 Technologies Used

* HTML5
* Tailwind CSS (CDN)
* Vanilla JavaScript
* Responsive Design
