# Day 36 – Cognitive Pattern Explorer

## Challenge
Day 36 of the #60DayClaudeChallenge

## Project

The Cognitive Pattern Explorer is an interactive self-reflection application that helps users discover their thinking and decision-making patterns through real-life scenarios.

It is designed as an educational reflection tool—not a psychological assessment—and encourages users to better understand how they process information, prioritize decisions, and respond under pressure.

---

## Features

- Interactive scenario-based questions
- Decision sliders
- Priority ranking activity
- Reflection journal
- Thinking pattern analysis
- Personalized insight dashboard
- Responsive modern UI
- Single HTML application

---

## What I Learned

Building this project reminded me that understanding *how* we think can be just as important as the decisions we make.

One key insight was that I naturally gather information and analyze situations before acting, but I also have an action-oriented side that becomes stronger once I gain enough clarity.
